# testigo
TESTIGO+ prototipo Meta Global AI Developer Hackathon 29-10-2026 | V1.0 Comprobar que una acción de pago propuesta por un agente coincide con la intención autorizada, la información presentada a la persona y la aprobación recibida. Cuando existe una diferencia material, TESTIGO+ bloquea la ejecución o solicita una nueva aprobación.
